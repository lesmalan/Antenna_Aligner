## 🚀 How to Use

### Quick Start (Recommended)
Simply **double-click** `RSL_Controller_v01.desktop` in the scripts folder.

The launcher will:
1. ✅ Verify virtual environment exists
2. ✅ Install/update all dependencies (including PyVISA, pyserial, etc.)
3. ✅ Launch the GUI

```bash

./launch_rsl_controller.sh
```

## 🔄 Persistence After Reboot

Dependencies are preserved because:
1. They're installed in the `.venv` virtual environment (stored on disk)
2. The launcher script automatically reinstalls from `requirements.txt`
3. If anything is missing, the setup runs automatically

If needed after a reboot, manually run:
```bash
./scripts/setup_dependencies.sh
```

## 🆘 Troubleshooting

**Icon won't launch?**
```bash
# Make launcher executable
chmod +x /home/sd2-group2/Documents/SD2_Codespace/Antenna_Aligner/scripts/launch_rsl_controller.sh

# Try manual launch
cd /home/sd2-group2/Documents/SD2_Codespace/Antenna_Aligner/scripts
./launch_rsl_controller.sh
```

**Missing dependencies after reboot?**
```bash
cd /home/sd2-group2/Documents/SD2_Codespace/Antenna_Aligner/scripts
./setup_dependencies.sh
```

**Serial port not found?**
- Verify Arduino is connected via USB
- Check port in /dev (usually /dev/ttyACM0 or /dev/ttyUSB0)
