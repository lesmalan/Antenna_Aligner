LAUNCH
------
Command Line:   python3 scripts/antenna_aligner_gui.py
Desktop:        Double-click Antenna_Aligner.desktop


TYPICAL SCAN WORKFLOW
---------------------
1. Connect Hardware
   ☐ Click "Connect Motor" → Arduino connected
   ☐ Click "Connect VNA" → ZNLE6 connected
   
2. Configure Frequency
   Single Frequency (Fast):
   ☐ Select "Single Frequency"
   ☐ Enter frequency in Hz (e.g., 977000000 for 977 MHz)
   
   OR
   
   Range Peak Tracking (Robust):
   ☐ Select "Frequency Range (Peak)"
   ☐ Enter start frequency (Hz)
   ☐ Enter stop frequency (Hz)
   ☐ Enter points (e.g., 201)

3. Manual Control (Optional)
   ☐ Use CCW/CW buttons to adjust azimuth
   ☐ Use Down/Up buttons to adjust elevation
   ☐ Current position shown in real-time
   ☐ Click "Home (0,0)" to return to origin

4. Select Scan Mode
   ☐ Azimuth Sweep (1D) - horizontal rotation
   ☐ Elevation Sweep (1D) - vertical tilt
   ☐ 2D Grid - complete az × el mapping

5. Set Scan Parameters
   Azimuth Sweep Example:
   ☐ Start Az:  -180
   ☐ Stop Az:    180
   ☐ Step:        10
   ☐ Fixed El:     0
   ☐ Delay:      1.0
   
   2D Grid Example:
   ☐ Az: -180 to 180, step 20
   ☐ El: -20 to 20, step 5
   ☐ Delay: 1.0
   → (19 az × 9 el = 171 points)

6. Execute Scan
   ☐ Click "Start Scan"
   ☐ Watch real-time plot update
   ☐ Wait for "Scan complete" status
   
7. Save Results
   ☐ Click "Save Data"
   ☐ Choose filename
   ☐ CSV and PNG automatically saved


FREQUENCY ENTRY FORMATS
------------------------
Enter frequencies in Hz (scientific notation OK):

977 MHz    →  977000000  or  977e6
1.5 GHz    → 1500000000  or  1.5e9
900 MHz    →  900000000  or  900e6


COMMON SCAN CONFIGURATIONS
---------------------------
Azimuth - Full 360° (Coarse):
  Mode: Azimuth Sweep
  Start: -180, Stop: 180, Step: 20, Fixed El: 0, Delay: 1.0
  → 19 points, ~20 seconds

Azimuth - Full 360° (Fine):
  Mode: Azimuth Sweep
  Start: -180, Stop: 180, Step: 5, Fixed El: 0, Delay: 1.0
  → 73 points, ~75 seconds

Elevation - Full Range:
  Mode: Elevation Sweep
  Start: -20, Stop: 20, Step: 2, Delay: 1.0
  → 21 points, ~25 seconds (at current azimuth)

2D Grid - Coarse Survey:
  Mode: 2D Grid
  Az: -180 to 180, Step: 30 (13 points)
  El: -20 to 20, Step: 10 (5 points)
  Delay: 1.0
  → 13 × 5 = 65 points, ~70 seconds

2D Grid - Fine Mapping:
  Mode: 2D Grid
  Az: -90 to 90, Step: 10 (19 points)
  El: -10 to 10, Step: 5 (5 points)
  Delay: 1.0
  → 19 × 5 = 95 points, ~100 seconds


TROUBLESHOOTING
---------------
Motor Won't Connect:
  → Check USB cable connected
  → Verify port: ls -l /dev/ttyACM*
  → Try /dev/ttyUSB0 if ACM0 fails

VNA Won't Connect:
  → Verify network: ping 192.168.15.90
  → Check VNA powered on
  → Ensure port 5025 not blocked

Scan Stops Early:
  → Check activity log for errors
  → Verify motor not at physical limit
  → Ensure VNA responding (not busy)

Plot Not Updating:
  → Normal - updates after each measurement
  → Check data point counter incrementing


OUTPUT FILES
------------
CSV Format:
  azimuth_steps,elevation_steps,amplitude_dB
  -180,0,-45.32
  -170,0,-43.21
  ...

Files Created:
  antenna_scan_<mode>_YYYYMMDD_HHMMSS.csv      (data)
  antenna_scan_<mode>_YYYYMMDD_HHMMSS_plot.png (plot)
  
  where <mode> is: azimuth, elevation, or 2d


TIPS
----
• Smaller step sizes = better resolution but slower
• Delay should allow motor vibration to settle (0.5-2.0 sec)
• Single frequency is faster if you know exact transmitter freq
• Range mode is more robust to frequency drift
• Peak marker shows optimal antenna orientation
• Save data before starting new scan (overwrites plot)
• Manual controls useful for finding approximate peak first
• 2D scans take longer - use coarse grid first to find region of interest
• Elevation limited to ±20 steps by hardware
• For 2D scans, increase delay if pattern looks noisy
